## Figure captions (numbers from analysis/results/test/)

**Figure 1.** (Hand-drawn; to do.) One case file with known contested points is described under ten requester framings. A judge labels each claim of the neutral description (N1). Counting detectors score a claim by how many other descriptions repeat it; reading detectors ask a model without the file.

**Figure 2.** Reading beats counting, and the kind of context barely matters. AUROC for the 327 unwarranted among 4,486 N1 claims (76 test case files, 3 generators), with 95% dossier-cluster bootstrap intervals. Blue: counting signals from two extra descriptions. Orange: closed-book readers. Gray: a smaller model that reads the case file (reference, not a ceiling).

**Figure 3.** A stakeholder's request pulls the description toward that side. Share of side-taking claims favouring each side in neutral descriptions (N1, 298 side-taking claims) and in descriptions requested by that side (A: 394; B: 449). Pooled H1a shift: +0.145 [0.100, 0.191].

**Figure 4.** Why opposed counting fails. Share of N1 claims repeated by both descriptions in each pair, split by true label (4,159 warranted, 327 unwarranted). Opposed pairs lose warranted claims (60% vs 71% for resamples) but repeat unwarranted ones at the same rate (115 vs 116 of 327).
